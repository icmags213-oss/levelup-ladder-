LEVELUP V22 — AUTOMATIC SYNC
Sign in under Settings > Automatic syncing on each device. Start syncing from the device with the latest data; use the online ladder on the other device.
Changes sync in real time while online. Offline changes stay queued. Conflicting edits pause syncing; download a backup and use the latest online ladder before re-entering missing changes.
Only approved coordinator emails can access the private synced data. Local backups and exported public standings remain available.
Use the complete ZIP when publishing; index.html needs its included scripts.
Supabase JavaScript client pinned to 2.102.0 (MIT license).
